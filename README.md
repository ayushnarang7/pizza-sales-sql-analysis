# 🍕 Pizza Sales Analysis — SQL Project

## 📌 Project Overview

This project analyzes pizza sales data using MySQL to identify sales trends, popular pizza types, ordering patterns, and revenue performance.

The analysis was performed on a relational database containing four tables: `orders`, `order_details`, `pizzas`, and `pizza_types`.

## 🛠️ Tools & Technologies

- MySQL
- MySQL Workbench
- SQL

## 📊 SQL Concepts Used

- SELECT, WHERE, ORDER BY, LIMIT
- Aggregate Functions
- GROUP BY
- JOINs
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions
- Date & Time Functions
- RANK()

## 🔍 Analysis Performed

The project answers questions related to:

- Total number of orders
- Total revenue generated
- Highest-priced pizza
- Most commonly ordered pizza size
- Top 5 most ordered pizza types
- Category-wise pizza sales
- Distribution of orders by hour
- Average pizzas ordered per day
- Top pizza types by revenue
- Revenue contribution by pizza type
- Cumulative revenue over time
- Top 3 pizza types by revenue within each category

## 📁 Project Files

- `pizza_sales_analysis.sql` — Contains all SQL queries used for the analysis.

## 🎯 Objective

The goal of this project was to apply SQL concepts to a real-world style sales dataset and derive meaningful business insights from the data.
